# Handover log

One file per piece of work, named `YYYY-MM-DD-<topic>.md` (newest = highest name): what Casper asked, what changed for
the player, how it was tested, what is still open. New files never conflict, so parallel branches can all add theirs.
Open items also go on [`../OPEN.md`](../OPEN.md). Older history (up to 21 Oct 2026) is in [`../UNFINISHED.md`](../UNFINISHED.md).
Latest first: `ls -r docs/log | head`.
