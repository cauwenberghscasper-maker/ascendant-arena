# Current direction: handcrafted 3D in a pixel-art game

User correction, 7 October 2026: the models should feel less AI-perfect, and
the game still has a pixel-art identity. The earlier tall, polished references
are exploratory drafts. Use `pip-reference-v3.png` for the current direction.

Compact roughly five-head heroic proportions; natural-colored noses; faces
with individual character; broad painted color planes and deliberate facets;
matte materials; sparse ornament; asymmetrical worn armor, stitched repairs and
scuffed boots. Keep the actual models 3D, with the existing overhead shooter
mechanics. Preserve the pixel-art UI, icons and arena presentation.

Wear must look deliberate and readable. Avoid random noise, excessive dirt,
photoreal pores, porcelain skin, identical decorative straps, tiny filigree,
glossy toy surfaces, clown-red noses and baby mascot proportions.

The previous four-model recovery job was cancelled after this correction.
No new hero model has been enabled on the live website yet.
